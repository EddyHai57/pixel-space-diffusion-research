# 工作计划

用户已确认两项任务并授权使用 subagent 分批执行。该计划落实 2026-10-15 对话中的目录方案；当前交付是资料与记录框架，模型和实验环境尚未选定。

## 第一批：组会前准备

- 负责人：论文备份子任务。核对五篇论文 metadata 和版本，下载原始 PDF，记录校验值和页数；失败需明确标记。验收：本地文件与来源、版本一一对应。
- 负责人：PixelGen 精读子任务。读正文与官方实现，整理训练目标、感知监督、门控、实验条件和限制。验收：主要结论有原文位置，公式约定一致。
- 负责人：框架调研子任务。比较研究结构和模型基座，区分像素/潜空间及推理/训练成本。验收：推荐与未验证项分开，硬件未知时不给虚假预算保证。
- 负责人：主任务。整合 README、记录模板、问题清单和会前材料。验收：本地链接可达、没有虚构会议决定或实验结果。

## 第二批：组会之后，按实际决定推进

1. 记录导师决定和负责事项，确认任务、数据、GPU 预算、基线与期限。
2. 核查并固定上游代码 commit、依赖环境、权重与数据来源；先做推理/数据检查，不直接全量训练。
3. 在明确授权和预算后执行最小实验：配置、种子、日志、失败样例与指标一并归档。
4. 一次只改一个核心因素，做同预算对照；若结果不支持假设，记录否定证据并调整问题。
5. 有稳定证据后建立论文论证：问题→方法→主实验→消融→限制；投稿目标确认后采用官方模板。

## 本轮检查

- 五篇 PDF 真实存在且可解析，不以网页可访问代替本地备份。
- BibTeX、CSV 和 manifest 的 ID、版本与 PDF 对应。
- Markdown 本地链接可达，模板和待确认字段有明确标记。
- 重点公式和报告指标抽查原文；未运行模型、未启动训练。
