# 研究问题与边界

更新：2026-10-15。来源：用户提供的导师聊天截图；以下是对研究意图的整理，不是已经确认的技术方案。

用户补充（2026-10-15）：算力尚未确定，明天组会上询问导师。不按本地或服务器 GPU 作默认假设。

## 已知目标

- 大方向：像素空间扩散（Pixel-space Diffusion）。
- 应用候选：约五秒短视频，暂不做长视频。
- 截图提到 bidirectional diffusion；具体结构、条件和任务尚需导师解释。
- 希望寻找较轻量、近期且效果可靠的基座。
- 首次组会前重点阅读 PixelGen（arXiv:2602.02493）。

## 必须澄清

| 问题 | 为什么影响实验 |
|---|---|
| 目标为纯像素空间视频，还是在潜空间视频模型上验证可迁移监督？ | 直接决定方法和基线能否支持最终论断 |
| 文生视频、图生视频，还是类别条件视频？ | 输入、数据和评估协议不同 |
| “双向”具体指时间维度全帧注意力、离线联合去噪，还是另一设计？ | 双向不自动等于某一种论文架构 |
| GPU 型号、数量、显存、可用时间和训练方式？ | 推理可运行不等于训练可运行 |
| 五秒对应多少帧、fps、分辨率？ | 时长本身不能确定 token 数或计算量 |
| 数据获取权限、规模和处理方式？ | 决定可复现性与第一阶段成本 |
| 第一阶段验收目标是什么？ | 图像理解、推理复现、短训练和正式消融应分开 |

## 表述纠正

像素空间表示不意味着按逐个像素自回归生成；具体 tokenization、patch 大小、时空压缩和注意力结构需核查。较新的模型也不必然在同一预算下更合适。生成五秒视频的潜空间模型可以作为参考基线，但不能直接证明像素空间视频方案可行。
